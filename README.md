# 多平台增长选品台

一个在本机运行的 PC Web 工具。目前支持追踪 1688 商品成交快照，并已接入抖音电商商机中心一期采集。

## 当前 MVP

- 1688 关键词多页搜索采集，使用独立的本机 Chrome 登录目录
- SQLite 保存商品与历史快照
- 增长榜、趋势评分、数据置信度
- 美容个护高风险宣称提示
- 按“品类—关键词”维护采集配置
- 可配置每日自动采集开始时间（13～23点）
- 每批最多5个关键词、每词1～3页，轮换覆盖全部词库
- 抖音电商商机中心机会词采集：搜索次数区间、成交增速、扶持权益和代发货源状态
- 1688与抖音使用独立榜单和评分口径
- 演示采集模式（连续运行两次即可验证增长榜）

## 启动

首次已经安装依赖时：

```bash
./start.command
```

或：

```bash
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

然后打开 <http://127.0.0.1:8765>。

## 第一次真实采集

1. 点击“采集 1688”。
2. 系统打开独立的 Chrome 窗口。
3. 如果出现登录页，请在两分钟内扫码或登录。
4. 登录会话保存在项目的 `data/browser_profile/`，系统不保存账号密码。
5. 第一轮只是建立基线；次日同一时段采集后，才会生成有效增长数据。

建议每天固定时刻采集。1688 页面可能改版；解析规则集中在 `app/collectors/alibaba1688.py`，方便单独维护。

第一次人工登录并成功采集后，可在首页开启“自动采集”。默认每天13点开始，按每批2个关键词、批次间至少30分钟完成当天词库；次日按相同顺序和近似时刻再次采集。

只有相隔20～28小时且同为“全网”或同为普通商品销量的快照才参与增长计算；异常暴涨或累计销量回落会从趋势排名中排除。

如果平台出现滑块安全验证，系统不会绕过验证：可见 Chrome 会暂停等待人工完成；后台任务会停止并提示需要手动验证。

若打开的是“验证码拦截”页面，建议停止采集一段时间，之后手动运行一批并在 Chrome 中完成验证。不要连续点击采集按钮。

系统对真实采集设置了30分钟服务器级冷却时间，防止按钮连点或后台任务频繁重试。

## 抖音电商一期

1. 在页面选择“抖音商机”，设置本次采集页数（建议先使用1～2页）。
2. 点击“采集抖音商机”。
3. 首次运行会打开独立Chrome窗口，请手动扫码登录抖店。
4. 系统进入“商机中心—追抖音热词”，读取账号正常可见的数据。
5. 登录会话保存在本机 `data/douyin_browser_profile/`，该目录已被Git忽略。

抖音一期数据包括机会词、搜索次数区间、平台提供的成交增速、推荐理由、扶持权益和代发货源状态。它不与1688累计销量混合计算。

## 演示验证

启动后连续点击两次“运行演示采集”，等待两次任务完成，即可看到增长榜。演示数据只用于验证产品流程。

## 测试

```bash
.venv/bin/python -m unittest discover -s tests -v
```

## 注意

- 只采集账号正常可见的页面内容，不包含验证码绕过或反风控规避。
- 页面显示的“成交”口径可能是累计值或滚动周期值，系统会保留原始文字供核对。
- “生发、防脱、祛痘、美白、消毒、医用”等词只做风险提示，最终上架前仍需核查资质与平台规则。
